# Public export

The initial public export preserves the sources and recorded test evidence of the PROPHET-XII delivery. It does not add DSP features or claim new hardware validation.

- Repository: https://github.com/AdhonisBR/prophet-xii
- Release: v1.0.0-experimental (prerelease)
- Complete delivery: PROPHET-XII-DELIVERY.zip and its SHA-256 sidecar, attached to the release.
- The delivery report is a historical test record from before this export; its statement that no repository was published describes that earlier implementation session. This export was explicitly requested afterward.
- No build caches, node_modules, SDK/NDK distributions or private signing keys are included in Git or uploaded as release assets. The ZIP includes the source-only dependency snapshot needed to review/reconstruct linked code.
- The original compiled deliverables are unchanged; standalone physical audio, Android device execution, Windows/macOS builds and commercial DAW use remain unverified.
