# DSP model and measured limits

This is an independent mathematical virtual analog interpretation, not a measured circuit clone or a reproduction of Sequential, Roland, Adam Szabo or Strymon proprietary algorithms. The original archive contained unsupported fidelity/performance claims; preserved baseline text is historical material, not delivery evidence.

## Oscillators

Saw and pulse use the continuous quadratic PolyBLEP residual. The historical function name `poly_blep_4` now forwards to the quadratic implementation: the baseline quartic was discontinuous at its piece boundaries. Triangle uses a cubic PolyBLAMP residual at both slope changes. Oscillator A tracks every wrap/pulse crossing and B's sync event at its analytical fractional sample position, delaying the output by one high-rate sample so both sides of each discontinuity can be corrected. A's inherited BLEP/BLAMP time weights were reversed and were corrected after a coherent FFT test demonstrated worse aliasing than a naive saw.

Osc B is evaluated for the current sample; Poly-Mod reads its previous **oversampled** output (one high-rate sample causal delay), not a control-rate approximation. This breaks the instantaneous cross-oscillator algebraic dependency explicitly. Exponential V/oct FM, PWM and cutoff modulation execute at 1×/2×/4×. LO FREQ bypasses B's bandlimiting. Simultaneous waveforms sum with square-root headroom normalization. Pink noise follows the inherited six-state coloration recurrence; it is not calibrated to sample rate outside the reference range.

## Filters

Curtis cascade: `y_i = G*x_i + (1-G)*s_i`, `G=tan(pi*fc/fs)/(1+tan(pi*fc/fs))`. Thus the composite state at pole four is `(1-G)*(G^3*s0+G^2*s1+G*s2+s3)`. The baseline omitted `(1-G)`. The DC coupling uses the same trapezoidal high-pass in the feedback equation and state commit: `HP=(1-Gdc)*(y4-sdc)`. Input saturation is evaluated **before** the nonlinear solve so Newton and state updates solve the same system. Up to six bounded Newton iterations with an early residual check solve the four-pole global loop.

The Moog-inspired ladder discretizes `dy_i/dt=wc*(sat(x_i)-sat(y_i))` with trapezoidal states. Each pole solves `y+g*sat(y)=s+g*sat(input)`; derivatives propagate through all four stages into the outer feedback Newton root. Inner/outer loops are bounded at eight iterations, stopping at a 1e-7 residual. This models the nonlinear differential pairs described in the consulted VintageLadders equations using a TPT solver instead of porting its RK implementation. It is not identical to the schematic shorthand `tanh(input-output)` in the request. The Padé saturation clamps at ±3 and uses its **actual rational derivative**, rather than the derivative of an unrelated exact tanh. An explicit regression checks both topologies' implicit equation residuals below 2e-5 at 48/96 kHz across cutoff settings.

Morph is a linear blend of independently processed filter outputs, with no claim of exact phase coherence or matched loudness. Endpoint-inactive filters do not keep running, so switching from an endpoint can expose stale state; parameter smoothing reduces but does not prove complete click elimination. Saturation, resonance and harmonic distortion are intentional.

## Envelopes, voices and smoothing

ADSR attack approaches 1.2 and trips at 1.0. Decay/release approach offset targets exponentially and terminate in finite time. Times are nominal RC controls; release-to-idle is not an exact prescribed duration for every starting level. Coefficients update only when ADSR/dispersion changes. Two ADSRs per voice run at base rate; envelope contribution is held within a high-rate group. Unison supports 1–12 voices, last/low/high priority, nonlinear detune, pan and glide. Stealing crossfades from the last actual mono voice output over 1.5 ms. This is a held-sample fade, not a second live old-voice renderer.

Fixed per-voice seeds produce reproducible tuning/cutoff/RC/VCA offsets. RC and frequency dispersion scale with Vintage. All LFO routing flags are connected. Cutoff/resonance and 24 continuous voice values plus output gain have one-pole smoothing. Waveform/mode switches and most effect controls remain discrete control changes. MIDI sustain, CC, aftertouch, bend and All Notes Off work through `prophet-control`. Ordinary note allocation is channel-agnostic; full independent same-note multichannel/MPE voice ownership is incomplete. Per-note MPE bookkeeping is limited to one mapped voice per channel, so do not treat this as a full MPE implementation.

## Oversampling and latency

Each 2× stage is a 65-tap Blackman-windowed sinc half-band FIR. Consecutive pairs share one continuous state, including both pairs in the 4× stage. Upsampling explicitly filters zero-stuffed input at unity DC gain; synthesis originates at the high rate and only needs the decimation path. The whole generator/VCF loop runs at high rate. Effects remain at base rate.

The decimator impulse peak is 16 base samples for 2× and 24 for 4×; 1× is zero. These values are reported to plugin hosts. There is no additional artificial delay inserted to match quality modes. Host latency compensation is therefore required for synchronization; standalone output is delayed by that filter latency. Oscillator A's one high-rate sample lookback is part of its phase convention, not extra audio-input transport latency. The FIR's transition band loses amplitude near Nyquist. The old undocumented >96 dB all-band claim is removed. See the measured stopband test and nonlinear alias comparison; neither is a universal alias bound for every preset, sync ratio or modulation.

## Chorus and reverb

The chorus has opposing triangular delay sweeps, Hermite interpolation, four-pole pre/post lowpasses, simple emphasis/de-emphasis, asymmetric soft saturation and optional pink hiss. I/II rates are 0.513/0.863 Hz with 1.66–5.35 ms delays. I+II uses 8.65 Hz and 3.3–3.7 ms. These are target characteristics, not verified MN3009 clock/switch/circuit equivalence. Hiss defaults to zero and silence remains silent.

Reverb has tempo-synced or millisecond predelay (clamped to 500 ms), four fractionally modulated allpasses, a 48-band log-spaced constant-Q analyzer with 15/120 ms envelope followers, and 2nd/3rd harmonic exciters. The three-phase 0.6/5.8 Hz modulation is distributed across bands. Harmonic generators above 0.45*fs are muted, rather than incorrectly clamped to a common high pitch.

An eight-line prime-delay FDN uses normalized Hadamard mixing, verified orthogonal. Sine plus smoothly changing fixed-seed random modulation affects delays. Feedback includes Hann dual-head granular shifting from −12 to +12 semitones and a +7 branch; the feedback blend is attenuated instead of adding unrestricted shimmer energy. Three formant resonators per line implement vowel morph **inside** feedback, followed by high/low damping and soft tank limiting. Coefficients cache high-cut/low-cut/RT60 changes. The decay control specifies nominal undamped line gain, not calibrated broadband RT60 after the formant and damping filters. The delivered impulse test requests 1.5 s with vowel/damping active and measures about 0.59 s at 48 kHz and 0.58 s at 96 kHz. Freeze disables excitation, modulation, shimmer and damping and reads integer delay lengths, with an emergency ±4 bound. Freeze is finite precision and is not a proven lossless infinite sustain under every transition. Ensemble follows band energy rather than exact fundamental pitch tracking; it is the explicit spectral interpretation in the prompt, not Cloudburst's proprietary engine.

## Real-time scope

All delay memory allocates before audio starts: predelay 524,288 bytes; diffuser 131,072 bytes; FDN 1,048,576 bytes; two shimmer rings 65,536 bytes, plus voice/state/host queues. At base sample rates through 192 kHz these capacities remain fixed. Kernel inline size and runtime RSS are recorded separately. Delay buffers moved from stack arrays to boxed slices during initialization to fix a reproducible test-thread stack overflow.

The DSP callback contains no network, file I/O, JSON, logging, locks or resizing. Standalone and Android use split `rtrb` endpoints. Network producers merge before the audio queue. Control draining is bounded; overflow/deferred work is visible where supported. The legacy local SPSC utility is deliberately not Sync, preventing the baseline's unsound unrestricted cross-thread multi-producer use. Params are individually atomic; bulk preset/state updates run on the audio owner. They are not a general transaction API for arbitrary simultaneous external atomic writers.

Allocation counters cover DSP processing, voice stealing, oversampling changes, and the native host callback including preset commands and telemetry production. They count allocations/reallocations in the exercised calling thread and do not prove every driver/framework path. Very small filter states are flushed to zero; portable FTZ/DAZ has not been enabled for every effect state, so denormal handling is partial. No manual SIMD voice packing was implemented. Deadline benchmarks are empirical on a shared x86 cloud machine; high Moog/4× loads can exceed deadline. There is no claim of universal Hard Real-Time safety, device latency, ARM power use, or commercial readiness.
